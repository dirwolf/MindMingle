DATA FLOW DIAGRAM
=================

1. USER REGISTRATION FLOW:
   User → Register → AuthController → User Model → JWT Token → Frontend

2. ANONYMOUS PROFILE CREATION:
   User → Create Profile → AnonymousController → AnonymousUser Model → Frontend

3. USER DISCOVERY:
   User → Search → AnonymousController → AnonymousUser.find() → Available Users

4. CHAT CONNECTION:
   User → Connect → AnonymousController → Chat.create() → Socket Room → Both Users

5. REAL-TIME MESSAGING:
   User → Send Message → Socket.io → Message.create() → Broadcast to Room → All Participants
